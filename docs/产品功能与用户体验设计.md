# 证件管家 · 产品功能与用户体验设计

> 文档状态：2026-09-27。从"制作/部署"到"面向大众客户使用"的完整功能与交互设计。
> 定位与架构见《项目介绍.md》《代码技术架构.md》；本文专注"做什么、用户怎么操作、怎样才算方便"。
> 面向读者：先给产品人和自己，把体验讲清楚；开发时可据此拆页面与接口。

## 0. 一句话设计观

```text
别人让你管理证件 → 你记，到期你才想起来 → 经常吃亏
证件管家        → 你只管登记一次，之后系统替你盯到期、替你备好"怎么办"
```

本产品不卖"管理功能"，卖的是"**别在办证这件事上吃亏**"。所有功能设计都围绕这个体验目标展开：
**录入要够快、提醒要够主动、续办要够省心、全家要管得住、数据要带得走。**

## 1. 三类角色与各自的"一条龙"

```text
制作/部署者（下载GitHub源码的人）
  下载/解压 → 双击启动脚本 → 自动装环境+建库+导种子 → 开浏览器 → 完成，零编译
管理员（维护"续办指南"内容的人，通常是制作者/部署者兼任）
  登录后台 → 逐类核对续办指南 → 缺失/过期则改 → 标来源+更新日期 → 用户即可见
最终用户（真正用这个工具记证件的人，最广的大众）
  打开→注册→把第一张证录进来→日常看提醒→到期前被通知→看怎么办→办完更新档案
```

三层各守其责，数据链条单向清晰：**管理员保证"指南正确"，用户负责"我的证件"，系统负责"主动提醒"。**

## 2. 最终用户的核心任务地图

用户其实只有 5 类任务，功能都围着它们转：

```text
 记录       我手上哪些证/卡会过期？
            （身份证/驾照/护照/居住证/社保卡/年检/储值卡/健身卡…）
               │
 知晓       现在这些离到期还有多久？
            （打开就看到：今天到期 / 30天内 / 已过期）
               │
 行动       到期前系统提醒我，并告诉我"怎么办"
            （要带什么 / 去哪办 / 多少钱 / 要多久 / 官方入口）
               │
 闭环       办完新证 → 旧的停用、新的入档，继续盯
               │
 守护       一大家子的都能管到，数据随时能导出带走
```

**任何功能如果不在上面某条任务线上，就不做**，避免堆砌。

## 3. 首次使用体验（Onboarding，关键中的关键）

> 大多数用户只给产品第一分钟。录入第一张证的门槛决定成不成交。

### 3.1 打开即见价值（首页空态设计）

用户第一次注册登录后，首页不是空白，而是"空态引导 + 一张示范卡"：

```text
┌──────────────────────────────────────────────┐
│  你好，我是你的证件管家 👋                       │
│  你还没有证件档案。                          │
│  ▍ 添加第一张证件（30秒完成）                  │
│                                               │
│  卡片示范（示意，非真实数据）：                │
│  ┌──────────────┐                            │
│  │ 🪪 居民身份证   ● 正常 尚有 1年2月          │
│  │    到期 2027-12-26                        │
│  │    「到期前 90/30/7 天」会提醒你            │
│  └──────────────┘                            │
└──────────────────────────────────────────────┘
```

- 引导文案用"口语 + 承诺结果"（"30秒完成""会提醒你"），不用功能名。
- 给一个"一键导入我常有的证"的**批量模板勾选**（身份证/驾驶证/社保卡/银行卡各来一张？），比逐张录快得多。

### 3.2 添加第一张证：点选为主、几乎不打字（已实现）

录入是最高频动作，表单按"能点选就不手填"设计，四步点完：

```text
① 证件类型   点磁贴（身份证/驾驶证/护照…），名称、常见年限、推荐提醒档自动带出
② 有效期     二选一：
             [🧮 签发日期 + 年限] → 点年限磁贴（驾照 6/10/20…），到期日自动算好并显示
             [📅 直接填到期日]   → 记得到期日的人一步到位
③ 归属成员   点 chip：我自己 / 家人（有家庭空间时出现）
④ 提醒档位   点 chip 多选（90/30/7 天前…），已按证件类型预选

证件号码 / 备注 → 收进"选填"折叠区，想填再展开（号码加密存储、脱敏展示）
```

- **到期日永远不用心算**：选"签发日 + 10 年"，系统直接给出计算结果提示条（"到期日期自动计算为 2035-06-15，无需手填"）。
- 每类证件的年限选项是**该类型常见年限**（身份证 5/10/20、护照 5/10、居住证 1…），而不是通用数字键盘。
- 提醒档位预选该类型的建议节奏（身份证 90/30/7，健身卡 30/7…），一键采纳。

### 3.3 首启三件套（3 分钟走完）

```text
① 注册账号（一次）
② 添加 1~3 张今天的证件（用模板点选最快）
③ 看一眼首页仪表盘（"未来30天有2项要办" → 形成"它真的会盯"的信任）
```

首页右上角放一个轻量"向导进度条：录入 → 看提醒 → 设置家庭"，非强制，可跳过。

## 4. 功能模块与前端交互（逐页拆解）

### 4.1 首页仪表盘（Dashboard）——"3 秒懂现状"

| 区域 | 内容 | 便利性点 |
| --- | --- | --- |
| 今日到期 | 今天要办的（默认置顶） | 第一个看到，绝不淹没 |
| 未来 30 天 | 未来一个月有几张要到期，按日期排 | 一眼知道近期压力 |
| 已过期 | 已过期但还没处理的（红色） | 不给用户留侥幸 |
| 最近提醒 | 最近收到的 5 条提醒 | 可点进提醒中心 |

交互惯例：**没有过期且 30 天内无到期时，显示一句轻松确认**（"近期没有到期安排，一切稳妥"），避免"红点焦虑"。

### 4.2 我的证件（Documents）——卡片流管理

- 每张证一张卡片：顶部状态渐变条 + 图标彩色底 + 名称 + 状态徽章（正常绿 / 临期橙 / 已过期红 / 已归档灰）+ 剩余天数 + 到期进度条与剩余百分比。
- **状态色贯穿** 徽章、图标底、剩余数字：临期偏橙、过期偏红、正常偏绿，一眼分清紧急程度。
- 剩余时长口语化（"约1年2个月"）+ 具体到期日；未填号码的证件显示"未填号码 · 去完善"一键引导，已填则脱敏展示号码与有效期。
- 卡片操作：**官方入口（主按钮，按省份一键直达）** / 怎么办 / 编辑 / 归档 / 删除。
- 顶部搜索（证件名 / 类型 / 成员）+ 状态筛选下拉；右上角"添加证件"。
- **列表按到期近日排序**，快到期的总在上，符合"最关心的在最上面"。

### 4.3 到期日历（Calendar）——把"到期"当日程

- 月视图日历，有到期的日期打点/变色，点某天看当天到期项。
- 三种警示色：未到（绿）/ 临期（黄）/ 已过期（红）。
- 年视图看全年分布（适合"今年要办哪些"，护照这种十年一次的最好预判）。
- 日历上点某项可直接跳续办指南（一步到底）。

### 4.4 提醒中心（收件箱）——"主动 + 可清账"

- 结构类似收件箱：未读优先，每条=「证件名 + 到期时间 + 距今天数 + 操作按钮」。
- 操作按钮三选一，都是"清账"交割：
  ```text
  [看续办指南]   → 跳到怎么办
  [已办新证]     → 弹出"录入新证"或"更新为已办"，原证停用，账清
  [延后通知]     → 改提醒档位，稍后再提醒
  ```
- 未读计数在全局导航标红；提醒一旦处理就不再重复顶置。

### 4.5 续办指南（Guides）——"怎么办"的答案库，按你的省直达

- **顶部省份选择条**：选一次"我所在的省份"，全站记住（与设置页联动）；换省份立即生效，无需刷新。
- 浏览首页：顶部"分类筛选胶囊"按证件类型一次点选，下方为对应类型的指南卡片墙（分类即直达，无需搜索）。
- **同类型自动选最佳版本**：本省版指南优先，没有才显示全国版；本省版带"××省版"标签。
- 每张卡片标准模板，整齐划一：
  ```text
  要带什么（材料清单）
  去哪办（办理地点）
  多少钱（费用）
  要多久（办结时限）
  官方入口 → 一键直达本省平台（广东→gd.122.gov.cn / 粤省事，浙江→zj.122.gov.cn / 浙里办…）
  来源 + 更新日期（＋"以当地窗口为准"免责）
  ```
- **入口按省份智能解析**：交管类（身份证/驾驶证/年检）直达本省 12123 平台；政务类（居住证/社保卡）直达本省政务平台；护照等全国统一的直达国家平台。该省链接暂未收录时回退国家政务服务平台，并在按钮下注明，**绝不给死链**。
- 从提醒中心/日历跳进来时**定位到该证件对应指南**，少一步查找。

### 4.6 家庭共享——"管一大家子"

- 建家庭空间 → 逐个添加成员（姓名+一个颜色）。
- 添加证件时可选"归属成员"，全家到期日历按成员配色区分。
- 家庭汇总页：所有成员的快到期一屏看完（适合操心老人孩子证的人）。
- 简版设计：家庭管理员统一维护成员与其证件，不追求"邀请对方注册"的社交复杂度（初版）。

### 4.7 数据导出——"心里有底"

- 一键导出 CSV：全部证件 + 提醒计划 + 状态，默认脱敏号码。
- 纯本地闭环：数据在你自己电脑/自己库里，可带走可备份，不给"数据锁死"的恐惧。

### 4.8 管理员后台（Admin）——保证内容"敢信"

- 证件类型管理：增删改，配图标/建议提醒档位/默认有效期规则。
- 续办指南管理：材料/地点/费用/时限/官方入口 + **来源必填 + 更新日期必填 + 免责说明**。
- 审计日志：谁在何时改了哪些指南（内容负责任的落点）。
- 管理端与用户端共用同一套"证件类型/指南"只读数据，改完用户即见。

## 5. 前端操作流的"关键路径"（只为最省点击）

把 5 类高频任务压成最短路径，任何一次都能在 2 次点击内到达：

```text
任务                    最短路径
──────────────────────────────────────────────
加一张证              首页[+添加证件]→模板选类→填到期日→[保存]
看有哪些快到期        打开首页(默认就是仪表盘)
处理一条提醒          提醒中心→[已办新证]/[看续办指南]/[延后]
查某证怎么办          提醒/日历点该证→[续办指南]
管家人                导航[家庭]→看汇总
导出                  [我的]→[导出CSV]
```

**设计红线：不让用户为"高价值低频"的事来回找**。必要的重活（录入、核对）一次性做足，日常查看零操作。

## 6. 从"制作/部署"到"面向客户"的全链路体验

这段是你要的"一条龙"：把部署者、管理员、最终用户串起来看，每一环都不卡壳。

```text
【制作/部署环·开发者】
 下载zip → 双击「启动-证件管家.bat」
  → 自动：预检Python/Node/MySQL(3306)/Redis(可选，缺则红字提示装哪个)
  → 自动：建venv装依赖 → 建库建表+空库补种种子指南(true幂等，绝不删用户数据)
  → 生成.env(首次问一次MySQL密码，JWT/加密密钥自动随机) → 启动前后端 → 自动开浏览器
  → 停止用「停止-证件管家.bat」；再次启动双击「启动-证件管家.bat」即可
  体验目标：从解压到打开，全程不用敲命令。

【管理环·管理员(可兼任部署者)】
 登录admin → 进入「指南维护」→ 系统已带种子(身份证/驾照/护照…)
 → 逐条核对，把"以当地为准"的空缺/待核实项补全或标TODO → 标来源+日期
 → 保存即上线，用户端立即可见
 体验目标：不要求一步到位，允许"已知的标注、未知的如实标TODO"，绝不臆造。

【使用环·最终用户】
 打开→注册→录身份证(模板30秒)→以后每天打开首页看仪表盘
 → 某天被提醒"你的护照还有90天到期" → 点[看续办指南]→看到材料/入口
 → 去办→办完回来[已办新证]→旧证停用、新证入档 → 继续被守护
 体验目标：录入一次，此后全靠系统主动；全程不需要懂任何专业概念。
```

## 7. 便利性设计清单（原则 → 具体做法）

| 原则 | 落到哪里 |
| --- | --- |
| 录入要快 | 全点选表单：类型点磁贴、年限点 chip、成员点 chip；号码/备注收进选填折叠区 |
| 不用算 | "签发日期+有效年限自动算到期"，计算结果直接显示确认 |
| 不用记 | 提醒档位按类型预选；缺啥系统默认给，可再改 |
| 不用找 | 首页即仪表盘；到期间置顶；提醒/日历直达指南 |
| 不用挑链接 | 选一次省份，官方入口自动直达本省 12123/政务平台；未收录回退全国平台并注明 |
| 不用等 | 每次改立即生效；状态自动算，不靠手改 |
| 不用怕 | 可停用可删除可导出；改错了能改回来；过期不隐形 |
| 想得到 | 全局搜索：证件名/类型/成员；指南按类型分类点选直达 |
| 防误伤 | 危险操作（删除/停用/改到期日）弹确认并提示影响（"将影响其提醒计划"） |
| 兼容大众 | 全程大白话、图标+配色表达状态，无术语；统一设计系统（渐变/卡片/圆角/阴影）保证整洁高级的观感 |
| 尊重隐私 | 首页/导出默认脱敏；敏感字段加密，用户可自查 |

## 9. MVP 范围 vs 进阶（分两步走，别一上来堆满）

**推荐先把个人单机版做扎实，再谈全家和 OCR：**

```text
▶ 第一版(MVP·个人版，必做)
  注册登录(JWT) / 证件档案增删改查
  到期日计算(模板+手动) / 到期日历
  多档提醒 + 提醒中心(幂等) / 续办指南(种子数据)
  首页仪表盘 / CSV导出 / 管理员维护指南

▶ 第二版(进阶)
  家庭共享 / 拍照OCR录入 / 年视图
  邮件/浏览器通知 / 多端/时区优化 / 密钥轮换管理

▶ 暂不做（避免复杂化）
  云同步 / 多机构多人协作 / 政务代办 / 支付
```

## 10. 体验走查：四个真实痛点怎么被解决

```text
痛点1 "银行卡/健身卡过期，钱白充"
  方案：模板可录"储值卡/会员卡"，默认提醒档高；过期前收到
        "卡里还有次数/余额赶紧用"的提醒 → 不浪费

痛点2 "驾照过期还开车=无证驾驶，出险不赔"
  方案：驾照模板默认+6年自动算；提前90/30/7天连续提醒；
        提醒点[看续办指南]给材料/体检/12123入口 → 不裸奔

痛点3 "一大家子的证，靠一个人脑子记"
  方案：家庭共享，全家到期一屏汇总，按成员配色一眼分清 → 不遗忘

痛点4 "去办证，材料带齐了还得跑两趟"
  方案：续办指南给出材料清单+官方入口，来源标日期 → 不白跑
```

## 11. 待你拍板的三个决策点

1. **录入方式**：第一版只做"模板点选 + 自由录入"（快且稳），OCR 拍照识别放第二版，可以吗？
2. **提醒渠道**：第一版只在站内"提醒中心"（本地离线即可用）；邮件/浏览器通知放第二版，可以吗？
3. **登录策略**：保持"必须注册登录（JWT）"，但注册只需一次、且连一次数据都不用填（模板/手动都可），可接受吗？

以上可再调整，确认后我们以此为准推进开发分解。
