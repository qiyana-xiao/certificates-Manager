# 证件管家 部署运行说明

> 文档版本：1.0
> 更新时间：2026-09-27
> 面向读者：要把本项目在自己电脑上跑起来的任何人。不需要会写代码，但需要会装软件、改配置文件。
> 业务背景见《项目介绍.md》，架构设计见《代码技术架构.md》。

## 1. 一图看懂部署全景

```text
                你的电脑（或服务器）
 ┌──────────────────────────────────────────────────┐
 │                                                  │
 │  浏览器 http://localhost:5173                    │
 │    │  Vue 前端（Vite 开发服务，端口 5173）         │
 │    │  所有 /api 请求转发给后端                     │
 │    v                                             │
 │  FastAPI 后端（Python 3.11+，UVicorn，端口 8000） │
 │    │            │                                │
 │    │            +---> Redis（端口 6379，可不用）   │
 │    +----------------> MySQL（端口 3306，必须）     │
 │                        库名 doc_keeper           │
 └──────────────────────────────────────────────────┘
```

两个依赖的"必须/可选"：

```text
MySQL 8.0    必须   唯一业务数据源，用户档案、提醒计划全在这，丢不得
Redis 7      可选   只存可重建状态（提醒去重键/限流/缓存），
                    没装系统自动降级，清空它不丢任何档案与提醒
```

（证件管家不依赖任何第三方 AI Key，离线即可完整运行，比前两个项目更省配置。）

## 2. 环境要求

```text
软件          版本下限      用途                检查命令
─────────────────────────────────────────────────────────
Python        3.11        跑后端(FastAPI)      python --version
Node.js       18          跑前端开发服务       node -v
MySQL         8.0         业务数据库          （服务里看）
Redis         7（可选）     缓存               （服务里看）
操作系统       Windows 10+  本文档以 Windows 为例
```

安装提示：

- Python 装好后 `python --version` 要显示 3.11 或更高；装 Python 时记得勾选 **Add Python to PATH**。
- Node 装好后要重开一个终端窗口，PATH 才会生效。
- MySQL 用 zip 免装版或安装器都行，记住 root 密码，后面启动脚本首次运行时会问你一次。
- **Redis 可选**：Windows 官方不直接发布。没装也完全能用——启动脚本检测不到会自动降级运行（提醒去重走数据库唯一索引，正确性不受影响、不丢数据）。想更快可装 Memurai / WSL 里的 redis-server，或在 3306 之外再加装后项目自动识别。

## 3. 首次部署：三步走（对小白最省事）

```text
 ①装好三样软件      ②双击启动脚本       ③注册使用
 ┌──────────┐      ┌──────────┐      ┌──────────┐
 │Python/Node│  ->  │启动-证件管家│  ->  │注册账号   │
 │MySQL(必须)│      │.bat(全自动)│      │添加第一张证│
 └──────────┘      └──────────┘      └──────────┘
  一次性            每次运行            一次性
```

> 一键脚本会自动帮你完成：检测环境 → 建虚拟环境装依赖 → 生成配置 → 建库建表 → 灌种子指南（**只在空库时，绝不重复也不删你已有数据**）→ 启动前后端 → 自动打开浏览器。
> 只要第①步的三个软件装好，其余都在后台自动完成，全程不用敲代码。

### 第 ① 步：导入数据库（一次性）

> 通常**无需手动执行**：双击「启动-证件管家.bat」会自动调 `scripts/init_db.py` 完成建库建表与种子导入（且只在空库时补种，安全幂等）。下面手动方式供想彻底掌控或排障的用户参考：

在项目根目录打开 PowerShell：

```powershell
mysql -u root -p < database\sql\01_schema.sql
mysql -u root -p doc_keeper < database\sql\02_seed.sql
```

输入 MySQL 密码后，脚本会自动建库 `doc_keeper`、12 张空表，并导入 31 个省份、证件类型与续办指南数据。脚本只建结构与知识库，不含任何个人数据；跑多少遍都不会把已有个人数据弄坏（幂等设计）。

没有 mysql 命令？用图形工具也一样：Navicat / DBeaver / MySQL Workbench 连接本机 MySQL，依次打开两个 SQL 文件执行即可。

验证：连上 MySQL 执行 `USE doc_keeper; SHOW TABLES;`，能看到 12 张表（users、document_types、provinces、renewal_guides、my_documents、reminder_rules、reminder_jobs、app_notifications……）就对了；再执行 `SELECT COUNT(*) FROM provinces;` 应显示 31 行，`SELECT COUNT(*) FROM document_types;` 应显示约 15 行。

### 第 ② 步：复制配置文件（一次性）

```powershell
copy backend\.env.example backend\.env
```

`.env` 是你的私密配置（已被 Git 忽略，不会被提交），`.env.example` 只是模板。

### 第 ③ 步：填写配置（一次性）

用记事本或任意编辑器打开 `backend\.env`，只需关心这几行：

```ini
DB_PASSWORD=你的MySQL密码        # ← 必填，改成第①步输入的那个密码

JWT_SECRET=please-change-this-to-a-random-secret-at-least-32-bytes!
                                # ← 必填，随便敲一段至少 32 个字符的乱码
                                #    例如键盘乱按：k9!vTq2#mXz8...

ENC_KEY=...
                                # ← 推荐填写：证件号加密密钥，32 字节明文经
                                #    Base64 编码后填入（例：Convert.ToBase64String(32随机字节)）。
                                #    留空则系统只用脱敏展示、不启用密文加密；
                                #    填了则证件号 AES-256-GCM 加密落库，安全性更高。
```

其他行（DB_HOST、REDIS_URL、APP_PORT……）保持默认即可，除非你的 MySQL/Redis 不在本机或改过端口。

### 第 ④ 步：一键启动（每次运行）

双击项目根目录「启动-证件管家.bat」，或在 PowerShell 里：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\start.ps1
```

脚本自动完成（每一步都有中文提示）：

```text
步骤0  检查环境：Python / Node / MySQL(3306) / Redis(可选，缺 Redis 自动降级)
步骤1  建/复用 backend\.venv 虚拟环境
步骤2  pip 安装 requirements.txt
步骤3  首次运行生成 backend\.env（会问一次 MySQL root 密码，随后用到底）
步骤4  建库建表 + 只空库补种种子指南（幂等，绝不删你已有数据）
步骤5  启动后端 8000（日志 backend\backend.log / backend.err.log）
步骤6  启动前端 5173（日志 frontend\frontend.log / frontend.err.log）
步骤7  轮询就绪检查通过 -> 自动打开浏览器
```

> 环境缺失时会在启动前就用 `[!!]` 红字提示缺哪样、去哪装，不会静默失败或中途卡死。

停止服务：双击项目根目录「停止-证件管家.bat」，或 `scripts\stop.ps1`（会连同子进程整棵树停止并清端口，二次启动不会报“端口被占用”）。

看到这个框就是成功：

```text
=====================================================
 证件管家已启动！
 使用入口     http://localhost:5173
 首次使用：注册账号 -> 添加第一张证件 -> 到期日历/提醒即刻生效
 停止服务：双击「停止-证件管家.bat」，或运行 scripts\stop.ps1
=====================================================
```

### 第 ⑤ 步：注册账号并登记（一次性）

```text
浏览器打开 http://localhost:5173
   |
   ├─ 注册账号（角色 user）-> 登录 -> 「我的证件」点"添加证件"
   |      点选类型磁贴(身份证/驾驶证/护照/…) -> 选"签发日期+年限"自动算到期（或直接填到期日）
   |      -> 点选提醒档位 -> 保存。提醒与续办指南即刻生效（默认提前 90/30/7 天）
   |
   ├─ 选一次「我所在的省份」（设置页或续办指南页顶部）：
   |      身份证/驾驶证等入口直达本省交管12123，居住证/社保卡直达本省政务平台
   |
   ├─ 想管一大家子：进「家庭共享」添加家人，共用一个到期日历
   |
   └─ 提醒效果：本地时间到点后在「提醒中心」看到该到期项
```

## 4. 手动启动（不想用脚本时）

后端（项目根目录下执行）：

```powershell
# 1) 建并进入虚拟环境（首次）
cd backend
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt

# 2) 读取 .env 里的变量到当前会话（FastAPI 本身不读 .env 文件）再启动
Get-Content .env | Where-Object {$_ -match '^[^#].+='} | ForEach-Object {
    $i = $_.IndexOf('='); Set-Item -Path ("Env:" + $_.Substring(0,$i).Trim()) -Value $_.Substring($i+1).Trim()
}
uvicorn app.main:app --host 0.0.0.0 --port 8000
```

前端（另开一个终端）：

```powershell
cd frontend
npm install                    # 首次
npm run dev                    # 启动在 5173，/api 自动代理到 8000
```

前端生产构建（部署到静态服务器时用）：

```powershell
cd frontend
npm run build                  # 产物在 frontend\dist\，任意静态服务器可托管
```

注意：生产部署时前端不再走 Vite 代理，需要把 `/api` 反向代理到后端
（Nginx 配一个 `location /api { proxy_pass http://127.0.0.1:8000; }` 即可），
并把 `.env` 里 `CORS_ALLOWED_ORIGINS` 改成真实访问地址。

## 5. 启动后验证清单

照着这张单子逐条点一遍，全过说明系统健康：

```text
[ ] 浏览器 http://localhost:8000/api/health/ready
    返回 status: READY（mysql: UP / redis: UP 或 DEGRADED）

[ ] 注册一个 user 账号能登录，进入「我的证件」

[ ] 添加一张"身份证"，点选类型磁贴，选"签发日期+10年"看到自动算出的到期日
    （或直接填到期日），保存后"到期日历"页能看到该证件亮起

[ ] 把某张证到期日临时改成未来 3 天，设提前 7 天提醒，
    过几分钟刷新「提醒中心」能看到这条提醒（或直接读数据库 reminder_jobs 出现记录）

[ ] 「续办指南」里能查到身份证/驾驶证等类型的材料与官方入口；
    在指南页顶部把省份切到别的省，确认入口按钮变成该省的 12123/政务平台链接

[ ] 在「数据导出」导出 CSV，打开文件证件号是脱敏显示

[ ]（安全性）配了 ENC_KEY：`SELECT doc_number_cipher, doc_number FROM my_documents` 看到的是类似
    密文而非明文号码；配了 JWT_SECRET：登录后过 `JWT_ACCESS_EXPIRE_MINUTES`（或手动退出）再请求会被 401
```

> 提醒是否真的到点，依赖你登记的到期日与机器本地时间；想立刻看效果，就把到期日改近、提前天数改大（如到期日=明天、提前2天），很快就能在「提醒中心」验证。

## 6. 降级运行说明（什么时候"少什么"也能跑）

```text
缺 Redis          系统继续运行：提醒去重退化为进程内 + 数据库唯一索引兜底，
                  首页聚合缓存退化为进程内（重启后重算）。
                  业务数据（档案/提醒计划/家人）完全不受影响。
                  想补上：本仓库未附带一键 Redis 脚本，可在
                  WSL / Memurai 中自行安装 redis-server，装好即自动启用。

Python 版本过低    启动脚本会提示并询问是否下载项目内便携版 Python 到
                  runtime\（仅本项目可用、不写注册表）。

MySQL 连不上      后端启动失败或就绪检查返回 NOT_READY —— 这是
                  唯一不可缺的依赖，请先启动 MySQL。
```

## 8. 常见问题

**Q1：启动脚本报"8000 端口被占用"**
上次的后端没停干净。双击桌面**「证件管家」**即可清理；若仍有残留，执行 `Get-NetTCPConnection -LocalPort 8000` 找到 PID，`Stop-Process -Id <PID> -Force` 结束它（5173 同理）。

**Q2：后端启动失败，日志里 Access denied for user**
`.env` 里 DB_PASSWORD 和真实 MySQL 密码不一致，改完保存重跑。

**Q3：就绪检查返回 NOT_READY / 503，mysql: DOWN**
两种可能：① 没执行第 ① 步的建库脚本；② MySQL 服务没启动。先 `Test-NetConnection localhost -Port 3306` 确认服务在，再确认脚本执行过。

**Q4：提醒中心一直空 / 不提醒**
检查三点：① 该证递状态是否"有效/临期"（添加或已过期会进入"过期"，不再提醒）；② 填的到期日是否正确、你的机器本地时间是否准确；③ 提前量天数是否小于到期剩余天数（如到期日就剩 3 天，设提前 7 天永远不会触发）。可参考第 5 节用"故意改近"的方式秒验。

**Q5：JWT_SECRET 相关启动报错**
密钥不足 32 字节会拒绝启动（安全设计）。随便编一段 32+ 字符的乱串填进去。

**Q6：中文乱码**
确认 MySQL 建库时用了 utf8mb4（第 ① 步脚本已内置，手敲建库才会漏）；浏览器乱码一般是终端编码问题，不影响数据库数据。

**Q7：怎么彻底重置演示数据**
停掉服务后执行：

```powershell
mysql -u root -p -e "DROP DATABASE doc_keeper;"
mysql -u root -p < database\sql\01_schema.sql
mysql -u root -p doc_keeper < database\sql\02_seed.sql
```

所有账号、证件、提醒清零，重新从第 ⑤ 步开始（种子知识库仍在）。

**Q8：怎么只重启后端不改前端**
按 Ctrl+C 停脚本（会同时停前端），然后参照第 4 节手动启动后端，前端窗口不动即可。
