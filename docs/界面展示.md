# 证件管家 · 界面展示

> 证件到期提醒与续办管理平台。签发日期 + 年限自动算到期，90/30/7 天分级提醒引擎，全国 31 省级行政区官方续办指南。以下均为系统真实运行截图。

**技术栈**：Vue 3 · FastAPI · MySQL 8 · Redis · AES-256-GCM 加密
