# 证件管家（Doc Keeper）项目介绍

> 文档状态：2026-09-27。本文描述项目设计目标与功能方案。技术细节见同目录《代码技术架构.md》。
> 技术选型与本项目主目录下的架构一致：**Python + FastAPI 后端、Vue 前端、MySQL 数据源、Redis 缓存**。

## 1. 项目定位

证件管家是面向**普通大众（个人与家庭）**的证件与卡券到期管理工具。把你的身份证、驾驶证、护照、居住证、房屋租约、车辆年检、各种会员卡和储值卡的"到期日"放进一个日历里，到期前按你设好的提前量主动提醒，并在你需要续办时，给出**要带什么材料、去哪办、多少钱、要多久**的官方办事指南。

一句话概括：**它不替你做任何政务手续，只负责让你"永远别把证件过期这事忘在脑后"。**

系统只做提醒与信息记录，不代登录政务系统、不代办任何业务、不作法律或政策结论。

两类角色：

- **普通用户**：添加自己的证件/卡券，看到期日历，接收提醒，查续办指南，导出备份；
- **家庭管理员**：把自己的证件分享到一个家庭空间，家人共用一个到期日历，谁的要到期一目了然；
- **管理员**：维护证件类型的续办指南知识库，标注信息来源与更新日期，控制内容质量。

## 2. 目标用户与需求

### 2.1 谁会用它

**所有有身份证的人。** 更精确地说：所有身上带证、名下有过期日期需要记的人——学生（学生证/银行卡）、上班族（居住证/社保卡/驾照）、车主（行驶证/年检/保险）、常出差出国的人（护照/签注），以及要操心一大家子的家庭主心骨。

### 2.2 他们到底痛在哪

这些是日常生活中反复出现的真实场景：

| 痛点 | 真实场景 |
| --- | --- |
| **到期了才知道** | 到银行办事，柜员说"您身份证过期了"，才发现已经过期半年，一堆业务全停 |
| **驾照过期=无证驾驶** | 过了有效期还开车上路，性质等同于无证驾驶，出险保险公司直接拒赔 |
| **关键卡券默默作废** | 某商场储值卡、某健身卡过期了，卡里余额和次数直接清零，钱白充 |
| **续办手忙脚乱** | 护照要续了，不知道要带照片还是户口本、去哪办、办多久，来回白跑政务大厅 |
| **一大家子记不住** | 老人家的身份证、孩子的疫苗本、全家各种证，全靠一个人脑子记，一忙就漏 |

### 2.3 为什么现成方案解决不了

- **手机系统自带的"日历"**：只记单个事件，没有"到期日 + 提前N天提醒"的概念，更不会有续办指南；
- **备忘录/待办 App**：要自己一条条写，到期了也只给个普通提醒，不给"怎么办"的答案；
- **政务 App**：只有"办业务"，没有"主动提醒你别过期"，你要自己想得到才去查；
- **通用任务管理工具**：面向工作流，对"证件到期"这种低频但后果严重的事，投入过量成本。

行业数据显示，**大量证件过期集中在"没人主动提醒"**——不是用户不想办，而是根本没想起来。所以这个工具要解决的不是"办证难"，而是"**不提醒就忘**"。便宜、简单、打开就能用，是本项目第一设计约束。

## 3. 为什么"这件事"值得做

把"证件到期提醒 + 续办指南"做成一个实用工具，比做分析型/内容型产品更合适，因为：

1. **人人都有**：证件和卡券是大众刚需，不挑人群、不挑城市、不挑年龄；
2. **后果是真实的**：驾照过期=无证驾驶、身份证过期=业务停摆、卡券过期=钱打水漂，都有真实的损失，用户有强烈动机使用；
3. **数据是官方的**：续办指南来自政务门户办事指南，不是拍脑袋，靠得住；
4. **粘性天然高**：证件到期是持续的、会反复发生的事，今天记了身份证，明天还会记驾照、孩子的护照。

**反过来说：如果只是做一堆"网页上能查到的办事信息"而没有提醒机制，就不值得做。** 提醒才是本项目的灵魂，续办指南只是提醒落地时的"变现"。

## 4. 主要功能

**面向普通用户（零门槛使用）**

| 功能 | 说明 |
| --- | --- |
| 证件档案 | 添加证件/卡券：点选类型磁贴 → 选"签发日期+年限"自动算到期（或直接填到期日）→ 点选提醒档位，几乎不用打字，全程不到一分钟 |
| 到期日历 | 月视图日历，未来 90/60/30 天内的到期项高亮分级（临期/即将/过期） |
| 首页仪表盘 | 今天的到期、未来 30 天内有几项要办、有没有已过期的，一眼看清 |
| 多档提醒 | 每个证件可设多个提前量（如 90 天/30 天/7 天），到期前按计划主动提醒 |
| 续办指南 | 每类证件配套"要带什么 / 去哪办 / 多少钱 / 要多久 / 官方入口 / 来源与更新日期"，本省版优先 |
| 官方入口·按省直达 | 选一次所在省份，身份证/驾驶证直达本省交管 12123，居住证/社保卡直达本省政务平台（粤省事/浙里办/京通…）；未收录时回退国家平台并注明 |
| 家庭共享 | 家人共用一个到期日历，谁的要到期一目了然，老人孩子的证也管得到 |
| 数据导出 | 全部档案与提醒计划一键导出 CSV，数据随时能带走 |

**面向管理员（内容维护）**

| 功能 | 说明 |
| --- | --- |
| 证件类型维护 | 增删改证件类型，管理通用提醒提前量与说明 |
| 续办指南维护 | 以官方办事指南为源，逐类维护材料/地点/费用/时限/入口，标注来源与更新日期 |
| 内容审计 | 指南增删改留痕，谁改的、何时改的、改了什么都能查 |

## 5. 效果示例

### 5.1 普通用户（睡前登记一张卡）

```
用户：把健身卡录进来吧，2027年6月30日到期，里面还有15节私教课
系统：（建档完成）已添加「健身卡 · 私教课」，到期日 2027-06-30。
     已自动设提醒：提前 30 天、提前 7 天。
     到时候没用完会提醒你，别让里的课打水漂～
```

### 5.2 到期前主动提醒（用户不用做任何事）

```
提醒窗口（不是用户主动来查，是系统推给他）：
------------------------------------------
⚠ 您的【居民身份证】还有 90 天到期（2027-12-26）
   过期后银行、铁路购票、手机号办理等业务会受影响。
   点这里查看续办指南：
   · 要带：原身份证（领新证时必须交回）、居民户口簿
   · 去哪办：各派出所户籍窗口 / 政务服务中心公安户政窗口
   · 费用：换领 20 元；丢失补领、损坏换领 40 元
   · 时限：约 1~30 个工作日（以当地为准）
   · 官方入口：国家及相关政务门户办事指南
   来源更新：XX省政务门户 2026-09（以当地窗口为准）
------------------------------------------
```

**注意设计点**：提醒的信息来自数据库里用户自己登记的到期日，**不是系统猜的**；续办指南来自政务官方办事指南并标注来源，**不是编的**；用户唯一要做的就是登记，之后全靠系统盯。

```
妈妈账号「家的小院」日历（一家三口的证都在上面）：

6 月 30 日  宝宝  儿童疫苗本（下次接种）← 未到
------------------------------------------
```

### 5.4 管理后台（管理员维护指南）

```
续办指南维护 · 证件类型：居民身份证
  材料清单  原身份证(必须在领取新证时交回) / 居民户口簿
  办理地点  各派出所户籍窗口、政务服务中心公安户政窗口
  费用      换领20元；丢失/损坏换领40元
  办结时限  承诺时限各地不同(约1~30个工作日)
  官方入口  https://...(政务门户办事指南)
  来源标注  XX省政务门户 2026-09
  免责提示  以当地窗口实际要求为准
```

每条指南都带"来源 + 更新日期"，管理员改过才有底气，用户也敢信。

## 6. 技术架构

| 层级 | 实现 |
| --- | --- |
| 前端 | Vue 3、Vite、Vue Router、Pinia、原生 fetch/axios、手写 CSS（无重型 UI 库，点名组件除外） |
| 后端 | Python 3.11+、FastAPI、UVicorn、SQLAlchemy 2、Pydantic v2 |
| 数据访问 | SQLAlchemy ORM + PyMySQL 驱动 |
| 数据库 | 一个 MySQL 8.0 数据库：`doc_keeper`（12 张表） |
| 缓存 | Redis（可选）：提醒去重键、限流、JWT 注销、首页聚合缓存 |
| 认证 | JWT（Access+Refresh+注销黑名单）、passlib Argon2/BCrypt 密码哈希、PyJWT HS256 |
| 敏感加密 | AES-256-GCM（`cryptography`）证件号密文落库，解密仅按需且不落日志 |
| 提醒引擎 | 自研调度：启动内存检查 + 每日定时重扫 + Redis 去重，**提醒只来自数据库，不靠外部定时平台** |

```text
Vue / Vite :5173
        |
        | /api
        v
FastAPI (UVicorn) :8000
  |       |       |
  |       |       +-- 提醒调度（进程内定时 + Redis 去重）
  |       +---------- Redis（可选）
  +------------------ MySQL doc_keeper
```

Redis **不是业务数据源**。清空 Redis 不会丢失任何证件档案、提醒计划或用户数据；MySQL 是唯一业务数据源，Redis 不可用时系统自动降级照常运行。

### 6.1 为什么不用外部定时平台 / 睡进程去跑提醒

提醒这件事容易被低估成"发个消息"。但"每天只该给同一张证发一次、不能重复、不能漏、断网重跑不能炸"这些正确性要求，外部平台和随手 sleep 循环都给不了保证，最后还是得自己管。本项目把提醒做成进程内确定性调度，用**数据库 + Redis 双保险**（见《代码技术架构.md》第 3 章）。

## 7. 添一张证：零门槛使用

> 目标用户是"会用微信的普通人和老人"。**他不接触 SQL、不接触代码、不接触配置文件。**

第一次进来的用户只做三件事：

```
第 1 步  注册登录（手机号/账号，一次）
第 2 步  添加证件：点选类型磁贴 -> 选"签发日期+年限"自动算到期（或直接填到期日）
         -> 点选提醒档位 -> 选填号码(加密存) -> 保存。之后的提醒、指南全自动。
第 3 步  选一次「我所在的省份」-> 官方入口自动直达本省 12123/政务平台
```

**到期提醒不是用户设置的，是系统算的。** 用户只负责登记事实，字段级规则、提前提醒、续办指南全部系统兜底。

## 8. 数据库

| 表 | 用途 |
| --- | --- |
| `users` | 用户、BCrypt 密码哈希、角色（user/admin）、省份、默认时区 |
| `document_types` | 证件类型（种子数据，身份证/驾照/护照……） |
| `provinces` | 省份知识库（31 省：交管 12123 子域名码、政务平台入口） |
| `renewal_guides` | 续办指南（材料/地点/费用/时限/官方入口/来源/链接模式，可分全国版与省份版，管理员维护） |
| `my_documents` | 用户证件档案（类型/到期日/号码密文/状态/备注） |
| `reminder_rules` | 每张证的提醒规则（提前天数，可多档） |
| `reminder_jobs` | 已生成的提醒记录（幂等去重：哪天给哪张证发过） |
| `family_members` | 家庭成员/分组与配色 |
| `export_logs` | 导出记录（审计） |
| `audit_logs` | 管理员写操作审计 |
| `system_configs` | 系统设置（提醒开关、保留期、缓存 key） |
| `app_notifications` | 每日通过弹窗/站内提醒（PENDING/DONE） |

**种子数据由开发者一次性导入**（`database/sql/02_seed.sql`），证件类型与续办指南是只读知识库；用户档案、提醒计划、家人分组全部由前端页面产生写库，用户全程不接触 SQL。FastAPI 启动时自动建库建表已关闭，只建一次。

## 9. API

| 路径 | 访问权限 | 作用 |
| --- | --- | --- |
| `GET /api/health`、`/api/health/ready` | 公开 | 存活与就绪检查 |
| `POST /api/auth/register`、`/login`、`/logout`、`GET/PUT /api/auth/me` | 公开/登录 | 注册、登录签发 JWT、注销、当前用户与省份设置 |
| `/api/documents/**` | 本人/管理员全家 | 证件档案增删改查 |
| `/api/calendar` | 本人/全家 | 到期日历聚合（月视图按到期日分组） |
| `/api/reminders/**` | 本人/全家 | 查看提醒、设置提醒规则、标记已处理 |
| `GET/POST /api/guides/**` | 所有登录用户查、管理员改 | 续办指南查询与维护（含省份版） |
| `GET /api/provinces` | 登录用户 | 省份列表（交管码、政务平台入口） |
| `/api/family/**` | 家庭管理员 | 家人分组与共享管理 |
| `POST /api/export` | 本人 | 档案与提醒导出 CSV / 上收件箱下载 |

错误响应统一为 `{ "error": "错误信息" }`，便于前端直接展示。

## 11. 配置与运行

配置通过环境变量提供，示例见 `backend/.env.example`。主要配置包括 MySQL、Redis、JWT 密钥。**真实密码与密钥不得提交到仓库。**

一键启动脚本（`scripts/start.ps1`）读取 `.env`、按需创建 Python 虚拟环境并安装依赖、构建并启动 FastAPI 8000 与 Vue 5173，通过 `/api/health/ready` 等待就绪后自动打开浏览器。

Redis 未配置时系统仍可启动，提醒去重/限流退化为进程内实现（重启后重复提醒由数据库兜底拦截），**不丢任何档案与提醒计划**。

## 12. 数据与隐私边界

- 认证用 **JWT**（短时效 Access Token + Refresh Token + 注销即失效），Token 带签名防伪，篡改即验签失败。
- 密码用 Argon2/BCrypt **单程哈希**存储，明文永远不落库。
- **证件号属极敏感信息，采用 AES-256-GCM 密文加密落库**（密钥 `ENC_KEY` 只存环境变量，不写进数据库/代码库），界面上全程脱敏展示（如 `110101********1234`），仅在用户本人查看详情时由服务端解密、且解密结果不落日志。
- 提醒内容只含必要信息（证件名/到期日/续办入口），不包含其他用户数据。
- 续办指南只读自知识库，来源与更新日期必标；用户操作产生的通知不含政策断言以外内容。
- 导出默认脱敏，审计日志只写操作类型与脱敏摘要。
